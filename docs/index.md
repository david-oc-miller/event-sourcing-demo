# Purpose

My event-sourcing-demo is for me to understand the concepts of event sourcing.  I don't intent it for use in real applications.

# Ideas to be investigated

1. Adding and retrieving events
2. Verifying event data against a JSON schema
3. Related events
4. Building current state of an entity from the history of events for that entity
5. Populating secondary repositories from the event stream
    * Database
    * Search
6. Generate an audit history for a user or for an entity
7. Access control
8. Checking business rules
